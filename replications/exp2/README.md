# Experiment 2: Diffusion

Three released diffusion-weight prompts are inventoried in [config.json](config.json) and [sources.json](sources.json). Each editor receives every prompt verbatim, once, with no tools and no feedback. The [shared CPU runner and scoring plan](../raw_weights/README.md) specify transport differences, hash checks, one-reply recovery and result locations.

The reconstructed `Images`-section scorer reproduces the authors' three shape-family labels. Correct shape-family labels do not imply a correct filled-versus-hollow description. [Source validation](../raw_weights/source-validation.json) is calibration of published answers, not a new replication outcome. New Astra and Fable outcomes are pending; [reference](reference) contains upstream result evidence.
